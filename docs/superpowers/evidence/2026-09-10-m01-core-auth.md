## Implementation

- `src/lib/auth/validation.ts` trims email input, validates a basic email shape, and enforces the milestone password minimum.
- `src/components/auth/auth-form.tsx` provides labeled login/signup controls, correct autocomplete semantics, pending state, accessible error/status rendering, and links between auth modes.
- `src/app/(auth)/auth/actions.ts` validates before provider calls, maps provider failures to stable bounded messages, constrains post-login redirects with `safeInternalPath`, requests signup verification through the configured application origin, and signs out server-side.
- `/auth/login` and `/auth/signup` render the reusable form boundary.
- `/auth/confirm` accepts only the expected email/signup OTP types, verifies `token_hash` server-side, redirects successful verification to `/app`, and routes malformed/provider failures to a bounded login error without logging the token.
- `docs/SUPABASE-AUTH-SETUP.md` records the required Supabase SSR confirmation-template/redirect configuration. Provider-backed verification remains a later M01 gate.
